# Shreeman Panda — Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Features
- Responsive layout for desktop, tablet, and mobile
- About, skills, projects, education, and contact sections
- Links to GitHub and the Shopping Trend Analyzer repository
- Mobile navigation menu

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `pandashreeman.github.io` (or use an existing portfolio repository).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your email address.
- Add your LinkedIn URL if you want it shown.
- Update project descriptions and status so they accurately reflect your latest work.
